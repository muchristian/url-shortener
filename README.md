### URL SHORTENER

The repository includes the implementation of Url shortener, which is built rest pattern.

### Prerequisites

To run or test this application endpoints, you have to have the following installed

- Java
- postgres db
- flyway for versioning migrations
- Postman or any other

### Testing (Step by Step)

- Open intellj and reconfigure application.properties for configurations to match your environment 
- Run the application
- Open postman and test
